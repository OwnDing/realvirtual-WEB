## 2026-10-24 实施验收记录

对象为 6.3.27，Linux aarch64、Playwright Chromium 156.0.8078.4、软件渲染。帮助源包含 24 篇核心页面、10 篇 IT 附录、每种语言 22 问 FAQ；生成器检查 96 个交付文件。附录的升级、安全运维保留来源语言并明确标识，不能称为完整英文翻译。录像为真实 UI 操作，含下载和诊断流程，三段时长分别为 164.40、162.80、140.68 秒。

- 文档治理、Lint、社区 TypeScript 和全量 Node 测试通过（87 文件、883 用例）。新增 Node 反例覆盖注入、缺记录/缺证据、生成漂移；客户工作区测试覆盖被裁剪的作者文档链接。
- 相关浏览器回归通过（最近一次 4 文件、46 用例），包括保存配额拒绝、错误语言切换、未知异常脱敏和帮助禁用/外部地址保持。
- 综合 `./scripts/verify.sh all` 在浏览器首分片失败：132 文件中 131 通过，1,352 用例中 1,351 通过。未修改的 `tests/script-host.test.ts:185` 预期 `hostTicks === 1`，实际为 0；该用例使用 5 ms 截止时间。随后该文件独立复核 15 用例通过。此结果表明失败未稳定复现，但不能将综合门禁记录改为通过；后续浏览器分片未由此次 all 执行。
- 供应链策略自测 10 用例通过；实际扫描失败。2026-10-24 报告发现锁文件中 `serialize-javascript@7.1.2` 的 GHSA-m5mm-p8h7-m29v（low，未分诊而被策略阻断），以及 100 项许可证失败记录（包括缺少文本和未解决义务）；依赖采集完整性为 900/900。未添加例外或更改门禁，不能据此批准商业发布。
- 最终 `./scripts/verify.sh build` 与 `npm run verify:help` 通过，内容摘要 `4527ece535bbf8c1a625d12d996e42b919c149acb9a53176a29d69772238d123`。HTTP `/training/` 子路径和断网 file URL 均验证了两种语言、搜索/无结果、旧路由/锚点、图片及三段视频；每段中英文字幕各 6 条，1080p 解码和编码时长核对通过。实际工作台 F1、错误脱敏、配方下载、HTML 导出与隔离接收者播放通过，帮助外部请求和接收者网络请求均为零。

生产旅程证据由 `npm run verify:help` 写入 `test-results/user-help/verification/`，包含结果 JSON、帮助/作者/接收者截图、实际下载的演示配方与 HTML；CI 归档该目录。媒体版本、UI 源摘要、录制输入与字幕摘要随 `docs/user/media/manifest.json` 和生成清单交付。临时测试日志不作为产品内容提交。

真实首次使用者走查未进行，不能宣称已证明 15 分钟上手。Windows/macOS 目标机器、真实 PLC/设备及独立安全认证不在这次本地证据范围。OD-006 保持 open；119 个专业域报错后续项保留责任登记。本次没有修改依赖锁文件、放宽安全门禁或变更持久化格式。
