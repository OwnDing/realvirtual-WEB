# 保存、重开与备份

## 适用条件
确认当前打开的是可写项目。文件夹项目需要浏览器文件夹授权；浏览器项目保存在当前站点和浏览器配置中。它们不等同于云端同步。

## 操作
1. 打开或创建项目，确认文档卡片显示正确名称。
2. 修改后使用文档的保存操作；只读文档按提示另存为项目副本。
3. 等待保存结果，再关闭并重新打开同一项目，检查修改是否恢复。
4. 在项目操作菜单使用可用的导出/备份功能，保留下载文件；文件夹项目也应按 IT 流程备份完整目录。
5. 在独立测试副本验证恢复。升级前按照随包升级手册备份和预检。

## 预期结果
重新打开后仍有已保存的文档和修改。导览 `.demo.json` 只含镜头与说明，不能替代项目或模型备份。个人语言和模板不自动成为项目数据。

## 失败处理
权限拒绝时重新授权正确目录；空间不足时先备份并清理无关数据，不直接清空业务站点。只读、名称冲突、项目切换或写入结果不确定时保留当前内容，检查目标文件后再决定是否重试。更换浏览器、协议、域名或端口可能隔离原本地数据，迁移前先导出。
