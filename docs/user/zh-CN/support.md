# 诊断与支持

## 故障发生时
先保留当前页面。刷新会清空本次会话的诊断历史。不要先清空站点数据，那里可能包含尚未备份的项目。

## 导出步骤
1. 打开 **设置 → 诊断与支持**，阅读采集说明。
2. 选择是否包含最近日志和场景摘要，点击 **刷新预览**。
3. 展开 **查看脱敏内容**，核对快照时间与实际内容。
4. 点击 **导出诊断包**，保存 ZIP。打包不可用时会明确降级为 JSON。
5. 自行审阅文件，再按客户支持流程决定是否发送。应用不自动上传。

## 预期结果
下载与预览使用同一快照，成功不代表环境已经通过健康认证。模型、截图、项目内容、设备名称、地址、凭证和信号值不包含在诊断包中；未知日志会省略。界面会标记不可用、截断和失败项。

## 环境检查与故障入口
点击环境检查可验证当前图形和存储能力。主动检查可能使用专用临时文件，不读取业务文件。加载或图形初始化失败时错误卡可提供诊断导出；JavaScript 根本未启动或浏览器进程已崩溃时无法保证导出。

## 下一步
向支持人员提供发生时间、版本、步骤、预期与实际结果以及已审阅的诊断文件。若保存或远程写入超时，先读回状态，不盲目重复。图形资源丢失后先保留诊断，再按提示重新打开模型。
