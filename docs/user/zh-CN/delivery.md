# 交付与访问控制

## 选择交付方式
离线 HTML 适合现场播放。受保护演示适合需要登录、访问有效期、撤销及服务端审计的场景，两者不能互换。

## 离线文件交付
1. 确认模型可以分发，导出 HTML 并检查文件完整。
2. 在接收机器断网打开，验证几何、文字和镜头。
3. 保留原模型和导览配方，以便修改后重新导出。

## 受保护演示
由管理员按随包运行手册创建演示资源与访问授权。访客使用获准的链接和登录方式。错误的链接、过期或撤销访问应由管理员核查；不要把账号或链接秘密写入支持截图。

## 预期结果与边界
离线文件包含可复制的模型数据，无法远程到期或撤销。受保护演示依赖客户服务器可用性，不能保证对方已取得的副本消失。浏览器界面的隐藏按钮不是服务端授权边界。

## 失败处理
未授权时先核对身份和资源授权。写请求断连后先读回状态，不假设请求没有执行。证书或服务器不可达由 IT 排查，不关闭浏览器安全设置。文件播放问题见 [支持](support.md)。
