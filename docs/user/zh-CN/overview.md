# 产品与环境

## 开始前
本手册面向数字孪生展示和销售演示的制作者、接收者与客户 IT。默认使用 WebGL；WebGPU 是可选 Beta，不能当作性能保证。完整浏览器和硬件认证范围以随版本的兼容性矩阵为准。

## 选择工作方式
1. 浏览模型：在工作台打开自包含 GLB，旋转、缩放和查看层级。
2. 制作演示：创建导览并导出 HTML。接收者不需要安装工作台。
3. 需要身份验证和撤销：采用客户服务器上的受保护演示；离线 HTML 不提供这些能力。
4. Planner 用于布局和组装，HMI 用于信息与信号，DES 用于离散事件建模。本册不承诺这些专业流程的完整培训。

## 环境检查
在设置 → 诊断与支持打开环境检查。根据使用目的检查图形、存储与权限。一次检查通过只说明当前能力，不是完整产品认证。工作台的安全上下文和企业证书由 IT 配置；不要关闭证书校验。

## 结果与失败处理
应能显示完整模型并操作视角。黑屏、资源加载失败或功能不可用时先查看 [诊断与支持](support.md)。浏览器本地项目可能被清理或逐出，应保留独立备份。学习流程见 [快速上手](quickstart.md)。
