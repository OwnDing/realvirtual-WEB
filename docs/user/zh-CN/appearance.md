# 风格与材质

## 适用条件
使用 WebGL 打开完整模型。材质修改需要资产编辑工作区和可编辑零件；工作台效果与独立演示播放器的光照不同。

## 操作
1. 打开 **视觉呈现 → 场景风格**，选择展厅、白底产品、暗色舞台、仓库或技术草图。
2. 调整亮度、背景、阴影和地面反射，观察实际模型。
3. **保存为项目默认效果** 才写入项目；个人模板仅在当前浏览器保存，可导出 JSON 备份。
4. 在 **材质** 选择基础材质并微调颜色、金属感、粗糙度或不透明度，再应用到选中零件。
5. 检查结果，必要时撤销/重做。完成后使用 **保存资产**。

## 预期结果
普通可编辑零件的外观发生变化，未选择的共享材质对象不被意外修改。预览卡只是风格示意，不能当作光学测量。

## 失败处理
只读引用先保存副本。纹理、多槽或运行时驱动材质不支持基础替换；混合选择被拒绝时缩小选择范围。部署锁不能通过修改个人设置绕过。切换模型或项目后重新确认保存目标。
