# 打开与导入模型

## 准备
首个演示优先使用自包含 GLB。CAD 格式能否导入取决于当前安装的导入器；不要把某台开发机的可用格式视为所有交付版本都支持。

## 操作
1. 在模型入口选择文件，确认格式与文件大小，等待进度结束。
2. 检查几何、纹理和层级是否完整。适配视角，确认没有落在模型内部。
3. 如果模型引用其他资产，先加载所有引用；离线交付需要纹理与资源自包含。
4. 需要修改时进入资产编辑工作区，并将只读库资产保存为项目副本。
5. 按 [保存与备份](projects.md) 保存可重开的工作成果，然后制作演示。

## 预期结果
显示完整模型而非占位几何。项目拥有编辑副本，库发布源保持不变。导出后仍需在接收环境验证。

## 失败处理
空文件、损坏 GLB、缺失引用、部署禁止的地址分别处理。先用随包示例确认环境；不要为下载失败放宽外呼策略。长时间加载不等于写入未发生，涉及项目保存时先读回检查。必要时保留页面并导出诊断包。
