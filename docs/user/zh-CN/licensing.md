# 授权、只读与功能不可用

## 先区分原因
功能不可用可能来自部署策略、用户访问授权、只读资产、浏览器能力或商业许可证状态。它们不是同一个开关。

## 操作
1. 读取界面中的具体状态与提示；记录软件版本和发生的操作。
2. 只读库资产需要修改时，建立可写项目副本。
3. 部署锁或账户授权问题交给管理员处理；个人设置不能放宽部署策略。
4. 许可证状态由管理员核对安装身份、主机匹配、有效期及文件签名。

## 预期行为
当前离线许可证约定到期后有三十天宽限期，期间保留全功能并显示横幅与水印；宽限期结束后进入只读。它是合同凭证与审计记录，不是浏览器硬件 DRM。具体部署必须与已批准许可证契约一致。

## 失败处理
不要更改系统时间、删除数据或修改模型来消除授权提示。保留当前工作并导出可用的诊断信息。若当前环境不具备目标能力，选择已验证的替代流程或在目标设备验收后再使用。相关说明见 [交付](delivery.md) 和 [产品范围](overview.md)。
