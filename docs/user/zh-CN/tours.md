# 导览与离线 HTML

## 适用条件
模型已完整加载、引用可解析且资源自包含。单文件演示首版不支持完整 HMI、任意脚本、工业连接、PDF 或 DES。模型上限为 128 MiB，HTML 因编码与播放器而更大。

## 制作步骤
1. 从当前文档卡片更多菜单打开 **演示打包**；使用透视相机。
2. 设定初始视角，添加镜头，填写标题和说明。
3. 调整镜头顺序、转场和停留时间，逐个预览。
4. 保存 `.demo.json` 配方。继续编辑时先打开对应模型，再打开配方。
5. 选择语言并导出 HTML，等待完整下载。
6. 在断网接收环境打开文件，测试导览、拖动接管、重播和复位。

## 预期结果
模型与相机导览能脱离工作台运行。拖动停止导览；页面隐藏时暂停，返回后继续。没有镜头也可导出自由浏览演示。工作台环境贴图和后处理不会全部复制到播放器。

## 错误与取消
无效配方应检查版本、镜头数量和时长。构建不匹配由 IT 重新交付同版本播放器产物。取消阻止迟到下载；重复导出需等待已有编码结束，不能同时启动多个编码任务。外部资源与脚本限制见错误提示，不以空模型假装成功。
