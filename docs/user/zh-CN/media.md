# 图片与场景录像

## 准备
媒体导出使用 WebGL 并退出 XR。场景录像不包含网页操作面板，也不录音。教程视频是另行录制的真实界面操作。

## 操作
1. 在 **视觉呈现 → 导出** 选择图片尺寸、构图和背景。
2. 显示取景框并调整相机；框内区域才会进入成品。
3. 导出 PNG 或 JPEG。透明背景仅适用于 PNG，会临时隐藏部分地面和后处理效果。
4. 录像选择手动、环绕或导览镜头，点击开始，倒计时后操作相机。
5. 点击 **停止并下载**，打开文件检查画面。浏览器优先使用可用 MP4 编码，否则输出 WebM。

## 预期结果
图片重新渲染到目标尺寸；录像为无声场景，目标 1080p/30 FPS，实际帧率依设备而定。录像最长三分钟且编码数据不超过 256 MiB。要求保留的水印进入成品。

## 失败处理
不支持编码时检查浏览器或改用图片。显存/尺寸超限时降低尺寸。切到后台会停止并下载已有片段；取消、关闭面板或切换模型会释放资源且不下载。错误后检查画布是否恢复，再查看 [支持](support.md)。
