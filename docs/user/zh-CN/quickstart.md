# 首次离线演示

## 准备
下载本手册随附的 [公开滚筒输送机 GLB](../../../public/library/PalletHandling/RollConveyor-3m.glb)，或有权分发的自包含 GLB。首次学习以十五分钟为目标；完成时间取决于模型与设备，并非保证。不要使用生产信号作为教程输入。

## 操作
1. 下载上面的示例，在工作台的模型入口选择该本地 GLB，等待资源就绪。录像使用同一 RollConveyor-3m 模型。
2. 拖动视图旋转，滚轮缩放。按 Shift+F 适配模型后调整视角。
3. 打开层级中当前文档卡片的更多菜单，选择 **演示打包**。
4. 使用透视相机，点击 **设为初始视角**，再点击 **添加当前镜头**。填写标题、说明和停留时间。
5. 转到另一视角，添加第二个镜头。逐个预览并检查先后顺序。
6. 点击 **保存导览配方**，保留下载的 `.demo.json`；模型应另行保存。
7. 选择演示语言，点击 **导出演示 HTML**，等待下载完成。
8. 将 HTML 复制到接收机器，断开网络后用允许本地 HTML 脚本且具备 WebGL 2 的桌面浏览器打开。点击 **播放导览**。

## 预期结果
接收者能看到模型、播放镜头并自由浏览。拖动画布会停止导览，再次播放从首镜头开始。HTML 内含完整模型，不能远程撤销；分享前确认资产分发权限。

## 失败处理
未解析引用应先回源文档加载；不支持脚本或外部资源时按提示处理。取消会阻止下载，已开始的编码可能继续释放资源。下载与播放都成功才算交付。进一步说明见 [离线导览](tours.md)。
