# 视觉呈现使用与兼容边界

在左侧边栏打开「视觉呈现」，依次使用「场景风格」「材质」「导出」。本功能不需要额外云服务、账户或 WebGPU。

## 场景风格

五种风格提供环境光、背景、地面、阴影和后处理组合。卡片是用途示意；模型本身的形状、材质和视角决定最终画面。参数修改只作用于本次展示；「保存为项目默认效果」才写项目设置，个人模板只存当前浏览器。模板 JSON 可导入导出，导入会替换当前个人模板集，建议先导出备份。

项目默认随项目设置文件保存。已有 `modelProfiles[稳定文档ID].presentation` 优先于项目默认；界面保存按钮写项目默认，保留所有文档配置。旧的内嵌浏览器设置仍能读取，首次显式保存升级到设置文件，不删除旧字段。部署锁优先，未知配方版本或文件冲突会拒绝保存，不自动重试。

设置 → 视觉仍提供详细参数。手工修改高级参数后会退出当前展示预设，界面会提示重新选择风格；避免把未表达在基础参数中的高级设置误存为预设。

## 材质

14 种基础材质支持颜色、金属感、粗糙度和不透明度微调。在资产编辑工作区选中零件并应用；一次操作可撤销和重做，共享原材质的其他零件不受影响。使用「保存资产」走原有资产文档保存流程；库源的修改保存成项目副本，不修改发布源。「恢复本次加载的原材质」在当前文档会话有效，恢复动作也可撤销。

只读引用、批量渲染源、纹理、多槽、物理材质扩展、特殊混合/面向、顶点色与运行时指示灯等不能用基础材质替换。混合选择中有不支持的对象时整个操作拒绝，不部分替换。透明防护板是普通透明材质，不包含物理折射。材质球示意不是光学测量结果。

## 图片与录像

默认输出 1920×1080 PNG。4K 为 3840×2160；纵向交换宽高，方形使用 1080×1080 或 2160×2160。「当前视口」按当前实际像素尺寸输出，仍受长边 3840 和 GPU 限制。导出前可按 Shift+F 适配整个模型，再调整视角。取景框表示中心裁切范围；输出重新渲染，不放大小图。网页面板不进入输出；选择框和辅助线隐藏，标注可以保留。

透明 PNG 暂时隐藏地面、反射、AO、泛光和轮廓后处理；JPEG 及录像不支持透明。成功、取消、错误后恢复画布尺寸、相机、背景、画质和辅助层。授权要求的水印保留在成品中。

录像不录屏幕、不录音频。分辨率使用 1080p 档及所选构图，目标 30 FPS；MP4 按浏览器能力优先，无法使用时输出 WebM。开始前倒计时三秒，可手动操作镜头、自动环绕，或导入 L2-2 的 `.demo.json` 镜头配方。导览使用透视相机；正交相机应使用手动或环绕。最长三分钟、编码数据不超过 256 MiB。进入后台会停止并下载已录片段；取消、切换模型/工作区或关闭面板时释放资源且不下载。编码器失败、超过硬限制或无法在停止后完成编码时明确报错，不能保证得到文件。

帧率显示为实际提交给采集画布的帧率，不代表最终编码器恒定 30 FPS；低端设备、大模型、后处理及高分辨率会降低流畅度。没有离线逐帧补算，也不更改工业仿真的固定时间步长。

## 对外能力说明

| 路径 | 本版承诺 |
| --- | --- |
| WebGL | 默认正式路径，五种场景风格、基础材质、图片和无声场景录像 |
| WebGPU | 可选 Beta；不是产品使用条件，也不保证更快。媒体导出入口提示切回 WebGL |
| WebGPU 效果 | 受原有能力表约束；反射不可用，AO 等后处理实现与 WebGL 有差异 |
| Gaussian Splats | 保留原插件；混合场景的遮挡、透明和录制性能需按目标模型验收，本轮未作兼容承诺 |
| 独立 HTML 演示包 | 延续原 L2-2 契约；不承诺复现工作台的全部风格及后处理 |
| 移动端、Safari、Firefox、硬件 GPU | 需额外实机验收，不以 Linux Chromium 软件 GPU 结果代替 |
