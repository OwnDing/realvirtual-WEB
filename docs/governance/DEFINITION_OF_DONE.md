# realvirtual WEB 任务完成定义

任务只有满足所有适用项时才能标记完成。

## 1. 范围与实现

- 已实现任务明确要求的用户行为和结果。
- Non-goals、未实现项、降级行为和范围偏差已披露。
- 没有空实现、固定值、隐藏 TODO、仅演示数据可用或私有 Stub 冒充完成。
- 修改位于允许范围；用户已有改动未被覆盖。
- 新增模块具备清晰责任、类型边界和对称生命周期。

## 2. 数据、兼容与安全

- 状态写入正确的权威来源，没有把部署、用户、项目和实时信号混存。
- GLB/rv-ODT、NodeId、项目文档、资产引用、端口和持久化兼容性得到验证。
- Schema/格式变化有版本、迁移、旧数据 fixture 和失败回滚路径。
- 工业写操作、MCP 写工具和真实设备范围符合 `AI_SAFETY.md`。
- Secret、客户模型和生产数据未进入仓库、日志或快照。

## 3. 工程验证

- `./scripts/verify.sh governance` 通过。
- 适用的 Lint、TypeScript 类型检查、Node 测试和浏览器测试通过。
- 用户可见功能至少有一个行为级验证；只通过类型检查不算 UI 完成。
- 构建、生成物漂移和公共构建路径通过。
- 性能关键路径有基线对比，且资源释放、拾取、选择和视觉正确性无回归。
- 验证失败没有通过删除、跳过、放宽或静音测试来处理。

## 4. 产品行为验收

适用时至少覆盖：

- 正常流程；
- 无效输入、不兼容设备/端口、重复操作和取消；
- 保存、关闭、刷新、重新打开和迁移；
- Undo/Redo、模型切换、插件禁用和资源清理；
- 桌面/触摸/键盘、语言切换和错误状态；
- 离线、弱网、接口断连、重连和写入结果不确定；
- 大模型、长时间运行或多用户冲突。

## 5. 文档与交付

- 活动 ExecPlan 的 Progress、Discoveries、Decision Log、Validation 和 Outcomes 已更新。
- 相关 ADR、产品规格、架构、契约、验收矩阵、迁移说明和生成文档已同步。
- 最终报告包含：修改范围、验证命令与结果、未运行门禁、偏差、风险和回滚方式。
- 真实 PLC/设备、CONNECT、移动浏览器、WebXR、性能或远程 CI 未验证时，明确写出证据缺口。
