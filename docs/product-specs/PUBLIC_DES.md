# 公开、行业无关的离散事件仿真

## 目的

让 XYvirtual WEB 的公开构建能够直接运行 DES（Discrete Event Simulation）：用户在 Planner/Editor 中组装和配置任意制造、物流或仓储流程后，可以单步、动画、混合或快进运行，查看事件、队列、产量、在制品、利用率和瓶颈，并保存可重现的模型配置与实验证据。

批准来源：用户于 2026-08-22 明确同意先为“公开的 DES”建立 ExecPlan，并强调产品不只面向涂装线。本规格因此把行业无关性设为产品验收条件，涂装线只是第一个端到端验收样例。

## 产品边界

DES 公共层只提供通用概念：

- 仿真时钟、确定性事件队列、优先级、取消和命名动作；
- 流动实体（MU）、组件、输入/输出端口、容量、阻塞、资源、队列和路由；
- 源、汇、处理站、缓冲/存储、输送、分支/合流、故障/恢复和时间分布；
- 运行模式、统计、快照、重现性随机种子、批量实验和结果导出；
- 公开组件注册与行为适配契约，允许行业插件增加语义。

DES 公共层不得识别 `PaintLine*`、喷漆配方、漆膜质量或特定厂商设备。涂装、焊装、装配、包装、仓储和物流的差异通过资产 `rv_extras`、通用 MaterialFlow 定义、项目行为或插件表达。

## 用户闭环

1. 用户把具有通用物料流组件的资产放入场景，使用稳定端口或显式逻辑连接建立拓扑。
2. 用户可配置到达间隔、处理时间、容量、路由、故障/恢复和分布参数；无效值、断路、容量冲突与无终点流程有可定位诊断。
3. 进入 DES 工作区后，公开构建不再显示“运行器不可用”，可以动画、混合、快进和逐事件单步运行。
4. 用户能查看当前仿真时钟、事件队列、实体位置/状态和组件统计；快进与动画模式在同一种子与参数下得到同一业务结果。
5. 用户可保存/恢复快照，用多个种子运行实验，对比产量、周期时间、WIP、利用率、阻塞/饥饿和瓶颈，并导出可审查结果。
6. 保存并重新打开项目后，结构配置与稳定引用恢复；运行时事件与 MU 不被误写回库资产。

## 通用组件与扩展

首个公开版本至少支持下列通用角色，名称与具体文件路径由技术契约固定：

| 角色 | 必需行为 |
| --- | --- |
| Source | 按确定值或分布生成实体，支持数量/终止条件 |
| Sink | 消耗实体并统计产出 |
| Station/Process | 处理时间、容量、并行工位与阻塞释放 |
| Buffer/Storage | FIFO 容量、拒收、释放与等待统计 |
| Conveyor/Transport | 输送延迟、在途失效语义与可选动画 |
| Router/Merge | 按稳定端口路由、分支、合流和回压 |
| Resource/Downtime | 资源占用/释放，故障、维修和恢复 |

第三方组件通过公开注册表和 `MaterialFlowDefinition` 扩展，不修改 DES 调度器。同一组件可以只支持连续仿真、只支持 DES，或共享逻辑同时支持两者。

## 状态与兼容边界

- 资产固有的组件、稳定端口与行为参数继续属于 GLB/`rv_extras`；项目放置、连接和实例覆盖属于项目文档。
- 仿真时钟、待处理事件、MU 位置、占用与组件状态是运行时事实，不回写库资产。
- DES 快照、运行历史和实验结果是有版本的派生分析产物，按项目/文档范围存储并可导出，不成为 GLB 的第二权威源。
- 现有连续仿真、MQTT/PLC 信号方向、稳定端口、项目文档和未知字段保留语义不变。
- rv-ODT v1.1 目前明确把 DES 插件组件排除在外；本任务建立独立、版本化的公开 DES 运行契约，不在没有另一个 Accepted ADR 时静默改变 rv-ODT 边界。

## Non-goals

- 不实现 MES/APS 生产订单执行、优化求解器或全厂级自动排产；
- 不把 DES 结果宣称为真实工艺质量、能耗、流体或安全认证；
- 不新增、替换或改变 MQTT/PLC/ThingsBoard 协议、方向、写权限与生产端点；
- 不引入账户、租户、云实验服务或多人审批；
- 不为了验收涂装线而在公共内核中硬编码涂装工艺。

## 验收

| 场景 | 预期 |
| --- | --- |
| 公开构建进入 DES | 真实运行器可用，不显示 stub/不可用提示 |
| 确定性排序 | 事件按时间升序、优先级降序、稳定序号升序执行；同种子结果可重现 |
| 通用流程 | `Source → Station/Buffer → Router → Sink` 在阻塞、恢复和分支下守恒实体并给出可解释 KPI |
| 多模式等价 | Animated/Hybrid/FastForward 在同参数下的产量、终态与统计一致；Step 每次只处理指定事件 |
| 快照与重开 | 快照恢复后续跑等价于不中断运行；项目重开后模型配置可重建 |
| 实验比较 | 多种子批量运行、取消、存储配额错误和导出均可观察 |
| 行业无关性 | 纯通用、物料搬运和涂装线三个黄金流程共用同一内核；架构门禁阻止公共 DES 导入 `PaintLine*`/Demo 模块 |
| 旧能力 | 连续仿真、旧 GLB/项目、MQTT/PLC 和 Planner 黄金流程不回归 |

真实 PLC/MQTT、客户模型、大规模仿真、多浏览器/GPU 和人工 UX 若未验证，必须分别披露。
