# L2-4 视觉呈现产品化

批准来源：2026-10-11 用户认可本会话完整方案并要求执行。

## 用户行为

统一视觉呈现入口提供场景风格、材质、导出。五种风格为工业展厅、白底产品、深色展台、真实车间、技术示意；缩略图与用途可见，支持亮度、阴影、背景、地面反射微调、恢复和用户模板。风格与 L2-3 性能档位分离。

项目展示配置随项目设置保存、重开恢复；个人模板可导入导出。十二至十六种公开基础材质通过现有可编辑资产文档应用，支持微调、撤销重做与保存。只读引用仍须显式复制为项目资产；不实现实例材质覆盖。带纹理、多材质槽与运行时状态材质明确拒绝不受支持的修改。

图片默认 1920×1080 PNG，支持 JPEG、当前视口、4K、横方竖构图、场景/纯色/透明背景。必须真实重渲染；辅助线默认隐藏，可选保留标注；部署水印保留。临时调整在成功、取消和失败后恢复。

录像为无声三维场景，支持手动、环绕、导览配方，1080p/目标30 FPS，倒计时、停止、取消、本地下载。MP4按能力提供，WebM回退；最长180秒且有体积上限。后台停止并尝试保存已录片段。禁止把重复帧当作稳定帧率。

## 边界

WebGL为正式验收基线；WebGPU可选实验路径，明确能力差异，不承诺更快或效果完全一致。Gaussian Splats保留现有功能，兼容验收单列。单文件HTML演示格式保持原契约，不承诺完整工作台效果。无云渲染、音频、桌面捕获、视频剪辑、物理折射或材质节点编辑器。

## 验收

风格→保存重开→图片；材质→撤销→重做→保存重开；三种录像→可播放文件。覆盖取消、切换、超限、坏配置、编码失败和资源释放。真实GPU及人工画面验收与自动化分开记录，性能和格式只按实测发布承诺。
