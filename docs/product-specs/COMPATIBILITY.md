# L3-2 兼容性矩阵与最低配置

批准来源：2026-10-19 用户同意本轮 L3-2 方案并明确“开 pr 实施”。

## 用户行为

客户 IT 可以离线读取中英文支持矩阵、功能限制、最低配置的认证状态和 HTTPS 信任手册。设置 → 诊断与支持提供独立环境检查入口。主动检查由用户启动，结果分别说明当前能力和产品认证；不因 API 存在、UA 或软件渲染通过而声称实机认证。

正式支持、有限支持、实验性、未验证、不支持是产品等级；能力满足、受限、未知是本次检查结果。未知不得转成通过。矩阵随产品版本冻结并有证据引用，版本号不设无穷上界。首批认证目标为 Windows 11 x64 Chrome/Edge；Linux、macOS、Firefox/Safari、移动端及 XR 分别登记。当前没有证据的目标保持未验证，不阻止可用功能运行。

## 场景

标准 WEB 使用受信任 HTTPS、WebGL2；浏览器项目额外验证 OPFS 往返；文件夹项目额外验证目录权限及保存重开。完整 Appliance 仍继承其 HTTPS、OPFS、健康/WSS 要求。单文件演示继承 L2-2 的独立功能范围。WebGPU 为本产品实验性可选路径；XR 当前仅支持经典 WebGL 渲染路径，按设备/系统/浏览器/VR或AR模式验收。

缺少文件夹访问 API 时解释浏览器项目及文件导入/下载的边界，不声称自动迁移或等价文件夹同步。权限拒绝、取消、存储失败、上下文丢失均有可观察结果。

## 支持窗口与硬件

滚动认证目标为发布时当前稳定版及前一主版本，实际承诺必须写出已经测试的有限版本范围；企业冻结版本单独登记。历史 143/145 声明没有充分矩阵证据，不沿用为完整支持。复核超期产生提醒，不机械撤销规范。

办公集显、独显工作站和 XR 三类参考档在实机留证前均不公布虚构 CPU/内存/显存最低数值。硬件认证记录 CPU、RAM、GPU/驱动、OS、浏览器、视口、画质、场景节点/三角形/材质/纹理/字节量；加载及帧率复用 [L2-3 规格](LOADING_PERFORMANCE.md)，至少 30 次正式采样。浏览器不可读的设备字段保持未知，软件 GPU 仅为功能证据。

## 边界与验收

标准浏览器访问无需浏览器扩展；CONNECT、部署运行时与 XR 系统组件分别说明。TLS 信任与离线许可证是两件事。L3-1 导出仍是被动采集；主动检查只操作专用临时文件及检查页自己的图形资源，不修改项目、不接入工业服务、不上传报告。

依据 [ADR-0018](../adr/ADR-0018-compatibility-evidence.md)、[契约](../contracts/COMPATIBILITY.md)、[验收矩阵](../acceptance/COMPATIBILITY.md)。真实 GPU、Windows、头显、企业证书/策略等没有运行证据时，认证项及对应计划里程碑保持未完成。
