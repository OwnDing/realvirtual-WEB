# L2-3 加载性能与首屏

批准来源：2026-10-08 用户同意当前会话 L2-3 方案并要求开发和创建 PR。

## 用户行为

普通 GLB 与旧项目继续打开。加载显示下载、校验、解码、构建、首帧和就绪状态，支持取消、重试；未知长度不得伪造百分比。可选性能包让只读轻量总览先显示，细节按视野与预算渐进加载；完整模型就绪前不开放编辑、精确测量或仿真。错误保留可用预览并明确显示尚未完整就绪。

提供自动、高、均衡、流畅画质。自动调整采用真实活跃渲染采样、迟滞与冷却，排除后台、空闲、加载；手动选择停止自动干预。自动降级不更改用户保存的视觉参数，不改变工业逻辑、信号频率或固定时间步。

## 边界

性能包是只读派生资源，原始 GLB、rv_extras、NodeId、项目和文档保持权威。逻辑只初始化一次，精确选择/拾取/高亮/导出继续读取原始几何。特殊动态几何保留原精度。不实现无限规模 out-of-core 工业运行；L2-2 单文件离线演示格式保持兼容。

## 目标与承诺

生产构建、1080p、100 Mbps/20 ms、固定参考设备，记录浏览器、节点、三角形、材质、纹理和资源总量。总览预算 3 MiB，标准源模型不超过 100 MiB：反馈 1 秒内、冷启动总览 P95 ≤ 5 秒、完整就绪 P95 ≤ 20 秒、低端参考机固定路线平均 ≥ 30 FPS。正式基准至少 30 次，冷/热分开；目标不是已验证结果。仅在真实参考机留证后发布量化销售承诺，不用软件 GPU 或 CPU 节流冒充真实低端设备。
