# L2-1 受保护演示访问控制

批准来源：2026-09-29 用户同意方案并要求写入文档、实施和创建 PR。实施计划为 [EP-ACCESS-001](../exec-plans/completed/EP-ACCESS-001-protected-presentations.md)。

管理员能够在客户 Appliance 发布固定版本演示、创建带到期时间的链接、指定访客账户或允许持链接访问、撤销链接并查询访问记录。访客只能查看该链接授权的资源，不能访问工作台、其它演示或工业/运维接口。

## 行为

- 本地账户分为展示管理员和访客，与现有 Appliance operator 分离；无公共注册。初始化和灾难恢复通过主机本地 CLI，密码不出现在命令行参数或日志。
- 发布完整自包含 GLB 快照；原有格式和稳定 ID 不变。外置模型依赖、脚本、远程文档引用必须在发布预检中拒绝，明确报告，不能静默暴露公开来源。后续可通过版本化契约增加多资源发布。
- 分享默认七天，可选择一天、三十天或自定义（最多九十天）。不提供永久链接。指定账户模式记录账户身份；持链接模式仅记录访客会话，不能宣称验证了真实自然人身份。
- 服务端随机会话 + HttpOnly/Secure/SameSite Cookie；不以浏览器存储、UI 隐藏或许可证状态决定授权。每次资源读取校验资源范围、账户状态、服务器时间与撤销状态。
- 撤销提交后阻止后续请求，旧会话同时失效。正常前台每十五秒及恢复可见时检查状态；无法验证时清除当前显示，停止加载和仿真。
- 访客页面复用公开 embed 引擎，不加载工作台与工业接口；显示身份/访客编号、演示名称与时间水印，内置截图包含水印。访客数据不写入项目草稿和离线缓存。
- 审计记录账户管理、登录结果、发布、分享创建/撤销、兑换、资源读取和拒绝；不记录密码、原始分享 token、Cookie 或原始 IP。默认保留九十天，可由部署管理员配置。
- 服务端故障失败关闭。写请求不自动重试，发布使用客户端操作 ID；撤销幂等且可读回最终状态。

## 边界

已传到浏览器的字节不能收回，水印不能阻止截屏或恶意客户端。断网导出包不承诺远程撤销。此阶段不实现组织、多租户、SSO、云端项目后端或新的工业写权限。

## 验收

正例覆盖发布、两类访客、读取、截图水印、撤销和重启。反例覆盖 localStorage 伪造、跨演示 ID、目录穿越、GET/HEAD/Range、CSRF、错误/到期会话、账户禁用、客户端时钟、服务故障和运维接口隔离。真实 Caddy + Node + 浏览器验证资源返回，不能仅使用 Mock 证明访问控制。回滚/恢复不允许复活已有链接。
