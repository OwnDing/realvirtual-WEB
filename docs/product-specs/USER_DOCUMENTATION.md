# L3-4 用户支持闭环

2026-10-23 用户明确同意完整方案并要求完成、开 PR，作为本规格、ADR-0020 和 EP-DOCS-001 的批准来源。

## 用户结果

首次使用者能够打开公开示例、调整视角、添加导览、导出 HTML 并断网播放；遇到失败可以找到对应帮助、理解下一步并主动导出诊断包。15 分钟是首次使用走查目标，不是未经实测的承诺。

## 范围

首版十二个中英文主题：产品与环境、快速上手、界面导航、模型导入、保存重开与备份、视觉风格与材质、图片录像、离线导览、交付与访问、授权和不可用功能、诊断支持、FAQ。每篇包括适用条件、步骤、结果和失败处理；FAQ 至少二十问。客户 IT 可在同一离线帮助包阅读安装、升级、兼容性和安全运维依据。

帮助复用按钮/F1 和上下文主题，跟随界面语言并可在同一主题切换；包含目录、面包屑、本地搜索、打印样式、截图和三段实际操作视频。两种语言内容及字幕随包交付，不调用外部 AI、搜索或视频服务。默认关闭和自定义文档地址仍由部署拥有。

错误治理覆盖模型加载、项目操作、演示打包、视觉呈现/媒体导出、授权访问和诊断出口。对候选逐项追踪来源与显示出口；已有错误码、内部断言和第三方异常不通过批量翻译来消除计数。用户出口显示可操作的本地化信息；未知异常不展示任意 message/对象。已显示的错误必须能随语言切换更新。取消、权限拒绝、配额、超时及结果不确定分别表达，不自动重试写操作。

## 边界

Planner/HMI/DES 提供定位与能力边界，专业操作手册后续扩展。OD-006 保持 open；旧根文档仍是 reference。安装实机、硬件最低配置、第三方安全认证保留原计划的未验证状态。单文件 HTML 包含模型且不可撤销，与服务端受保护演示分开说明。内建录像仅采集场景，教程必须录制真实 UI。

## 验收

见 [验收矩阵](../acceptance/USER_DOCUMENTATION.md)。机器门禁覆盖双语对应、来源、链接/锚点、资源、生成漂移和错误出口；生产浏览器覆盖子路径、离线、语言切换、搜索、错误及下载。真实首次使用者走查和目标机器验收单独记录，不能由自动化替代。
