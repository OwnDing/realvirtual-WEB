# PS-LICENSE-001：授权与到期行为

## 1. 这是什么

私有化部署的客户在**内网完全不可出网**的条件下，需要一份能证明「这套部署对应哪份合同、包含哪些功能、有效到哪天」的凭证。本规格定义该凭证的用户可见行为。

**它是合同凭证与防篡改审计记录，不是访问控制。** 本产品为 AGPL-3.0-only，客户收到完整源码并有权修改（`LICENSE:376`）。签名保证凭证内容不可伪造、不可篡改；它不保证、也不试图保证无人能绕过校验。违约救济在合同，不在代码。

对客户可以直白这样说：**我们不锁你的机器。我们给你一份签了名、改不了的凭证，双方都拿它对账。**

## 2. 用户能做什么

| 角色 | 行为 |
| --- | --- |
| 交付工程师 | 把一个 `license.rvlic` 文件放进部署目录，无需联网、无需激活、无需重启服务 |
| 车间操作员 | 到期前后都能继续开机、看画面、连信号、下发指令；到期时看到清楚的提示，而不是黑屏 |
| 工厂设备管理员 | 在设置页看到许可证 ID、客户名、到期日、剩余天数、功能位、合同上限与当前用量 |
| 售后支持 | 拿到一份可离线核对的凭证，据此判断现场装的是哪份合同 |
| 销售 | 有一份与代码行为逐条对应的到期条款可以写进合同 |

## 3. 到期行为（用户可见）

到期不是一个开关，是一条坡道。**产线在任何一格都不停。**

| 阶段 | 时间 | 用户看到 | 用户失去 |
| --- | --- | --- | --- |
| 正常 | 到期前 30 天以上 | 设置页一行状态 | 无 |
| 临近到期 | 到期前 30 天内 | 可关闭的提醒，每天再出现一次 | 无 |
| 宽限期 | 到期后 30 天内 | 不可关闭的横幅 + 角标水印 | 无 |
| 只读 | 到期 30 天以后 | 不可关闭的横幅 + 角标水印 | **只失去保存新更改** |

**永远不会失去**：3D 画面运行、信号接入与刷新、PLC 读写、报警、KPI、趋势、多用户观察、打开与查看既有工程。

这条红线是安全要求不是商务要求。HMI 是操作界面；一个突然无法下发停机指令的 HMI 是安全事故，任何商务条款都不能要求它。

只读阶段点"保存"，按钮仍然可以按下，并明确说出为什么不能保存以及怎么恢复——不是静默失败，也不是灰掉一个没有解释的按钮。

## 4. 异常情况的行为

| 情况 | 行为 |
| --- | --- |
| 部署未声明需要许可证 | 授权功能完全不启用，**界面上没有任何授权相关文案** |
| 许可证文件缺失 | 提示缺失，**不锁定** |
| 许可证文件损坏或签名不符 | 提示无效，**不锁定** |
| 浏览器无法做签名验证 | 提示无法验证，**不锁定** |
| 绑定信息与实际部署不符 | 说明性提示，写明凭证声明的与实际运行的分别是什么，**不锁定** |
| 系统时钟被拨回 | 提示时钟异常并按凭证签发日兜底，**不锁定** |

「拿不出有效凭证」的后果是审计上说不清，不是运行时被惩罚。绑定不符在现场压倒性地是正当运维事件——迁了主机名、从备份恢复到新机器——按篡改处理只会制造支持工单。

## 5. 明确不做

- **不做技术强制**：不混淆、不反调试、不自校验、不完整性自检。客户持有源码，这些无效且与 AGPL 的源码交付义务冲突。
- **不做联网激活、不做吊销列表、不做遥测回传**：违反默认零外呼（Approved `PS-CONFIG-001`）。
- **不做机器/硬件指纹**：浏览器内不可实现。
- **不强制席位与信号上限**：浏览器看不到其它浏览器。上限是合同条款，界面只如实展示用量，不拒绝。
- **不阻断运行与操作**：见 §3 红线。

## 6. 到期条款（可直接引入合同）

> **授权凭证与到期行为**
>
> 甲方交付的软件为 AGPL-3.0-only 开源软件。乙方依本合同获得的是软件的交付、部署实施、技术支持与保证服务，以及一份由甲方签名的授权凭证文件；乙方在 AGPL 下就软件本身享有的复制、修改与再分发权利不受本合同限制。
>
> 授权凭证记载授权标识、客户名称、签发日期、有效期截止日、功能范围、绑定信息与合同上限。凭证以离线方式校验，运行期间不向甲方或任何第三方发起网络请求。
>
> **有效期届满不会导致软件停止运行。** 届满后 30 日内为宽限期，软件功能不变，界面显示到期提示与水印。宽限期届满后，软件的运行、数据接入、设备读写、报警与监视功能**继续全部可用**，仅停止保存新的工程修改，界面保留到期提示与水印。
>
> 双方确认：上述到期行为为软件的既定行为，甲方不通过技术手段中断乙方的生产运行。乙方在有效期届满后继续使用超出授权范围的功能，构成本合同项下的违约，双方依本合同违约条款处理；甲方不以停机、锁定或远程禁用作为救济手段。
>
> 乙方续期后，由甲方签发新的授权凭证文件，替换部署目录中的原文件即刻生效，无需停机、无需联网。

## 7. 验收

| 场景 | 期望 |
| --- | --- |
| 断网 + 放入合法凭证 | 正常状态，无横幅，设置页显示凭证信息 |
| 断网 + 时钟拨到到期后 15 天 | 宽限期：横幅 + 水印，保存仍可用 |
| 断网 + 时钟拨到到期后 45 天 | 只读：保存停用并说明原因；**PLC 写、信号刷新、画面运行断言未受影响** |
| 时钟拨到 1970 | 按签发日兜底，不进入未到期状态；显示时钟异常提示 |
| 删除凭证文件 | 提示缺失，不锁定 |
| 改动凭证任意一个字节 | 提示无效，不锁定 |
| 部署未声明 `required` | 界面上找不到任何授权文案 |
| 明文 HTTP 局域网部署 | **签名验证成功**，不是"无法验证" |
| 把凭证换成另一台机器的 | 说明性提示，写明两边的绑定值，不锁定 |
