# L2-2 单文件离线演示包

批准依据：2026-10-06 用户要求新分支推进 L2-2，并明确选择「单个 HTML，双击离线打开」。路线图仅作为需求背景，历史代码判断以本次取证为准。

- 从当前文档入口打开演示打包面板，复用已经导入 CAD/GLB、编辑材质与元数据的工作流。
- 记录当前透视相机为初始视角或导览镜头；每个镜头可编辑标题、说明、移动和停留时间，并可预览、排序、删除、设置循环。
- 导览配置可下载为版本化 JSON 并重新导入；不隐式写入项目、全局偏好或源 GLB。导出 HTML 内持有完整导览配置。
- 一次导出生成单个 HTML，包含当前文档的自包含 GLB 快照、播放器、导览、必要说明与许可证。无需服务器、Node、安装或首次联网；独立播放器复用公开 embed 引擎与 director。
- 收件人可开始/停止导览、切换镜头、旋转缩放和回到初始视角；隐藏标签页暂停，关闭页面释放资源；中英文跟随导出选择。
- 所有引用必须已经解析并嵌入；缺失引用、外部资源、可执行模型脚本、未支持压缩格式、损坏 GLB 或超限时明确拒绝，不导出缺内容的成功文件。标题和说明按纯文本显示。
- 首版快照上限 128 MiB、导览上限 50 个镜头；导出过程有忙碌/失败/取消反馈，切换文档后旧操作不得下载错误文档。
- HTML 不携带账户、Cookie、服务器配置或工业连接。它是接收者可复制的离线文件，不继承 L2-1 的有效期/撤销/身份审计；界面明确展示这一边界。
- 首版仅承诺公开 embed 的几何/材质与内建连续仿真；不把完整 HMI、外部 PDF/网页、任意 TypeScript 导览、工业写操作、WebXR、DES 或完整工作台打进文件。现有富导览 API 不改变。

实现依据：[ADR-0013](../adr/ADR-0013-single-file-demo-package.md)、[格式契约](../contracts/DEMO_PACKAGE.md)、[ExecPlan](../exec-plans/completed/EP-DEMO-005-single-file-demo.md)。
