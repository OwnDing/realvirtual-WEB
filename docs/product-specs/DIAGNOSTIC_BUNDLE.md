# L3-1 本地诊断包

批准来源：2026-10-13 用户认可本轮方案并明确“同意。执行”。

客户在设置 → 诊断与支持查看采集范围和脱敏预览，一键下载 ZIP，自行决定是否发送。生产公开构建必须可用，无需 CONNECT、AI 或私有模块。中文/英文、键盘/触摸、部署设置锁和 Kiosk 可见性必须保持。

包包含环境、应用版本、GPU/实际渲染后端、场景数量摘要、最近应用日志与异常。范围开关可排除日志或场景。加载失败/上下文丢失的错误卡提供导出入口；基础启动已运行但 Viewer 未创建时仍能导出环境与异常。无法执行 JavaScript 或浏览器进程崩溃不在保证范围。

默认不外发、不探测服务、不写工业信号、不修改项目。诊断缓存只在页面内存，刷新清空；不包含资产、截图、源码、生产信号值、客户命名、连接地址、凭证、浏览器存储转储。无法安全判断的自由文本/对象省略。用户预览与导出使用同一脱敏快照。

采集项独立容错，可取消、防重复。场景切换时废弃不一致的场景摘要。ZIP 不可用降级到单个 JSON。字段不可读、截断、失败和省略必须可观察，不伪装成功。

不包含服务端日志合包、在线工单、自动上传、跨刷新留存、原始数据模式、真实设备主动探测。

依据 [ADR-0017](../adr/ADR-0017-local-diagnostics.md)、[包契约](../contracts/DIAGNOSTIC_BUNDLE.md)、[验收矩阵](../acceptance/DIAGNOSTIC_BUNDLE.md)。
