# ADR-0019：供应链证据与内容绑定的代码执行授权

## Context

用户于 2026-10-20 批准 [EP-SEC-001](../exec-plans/active/EP-SEC-001-supply-chain-and-script-security.md) 并要求开 PR 实施。现有五道门禁不判断依赖漏洞和许可证；已有 SBOM 未建立完整的包身份/分发证据。工作台 URL 可开启 QuickJS，原生项目代码同意按项目 ID 持久，代码变化不使旧授权失效。

## Decision

1. 新增同入口的 `Supply Chain Gate`，分别产出漏洞、许可证和清单完整性结论。High/Critical、未知许可、缺输入与工具错误失败关闭，所有直接/传递/开发/平台依赖均登记。例外只按精确证据、Owner 批准与有效期生效，默认没有例外。
2. 锁定的 npm audit、CycloneDX 与 SPDX parser 是开发工具，不增加客户启动外呼。仅公开 registry 的已验证依赖树允许在线审计；私有输入必须换经批准的数据源。扫描不修改依赖，修复是独立、可审查的变更。
3. 开发树、WEB 制品、Appliance 制品各有清单。交付证据以实际文件摘要和镜像 digest 为准，生成源唯一。缺供应商/原生/WASM 证据保持未验收，公共 npm 通过不放行整个商业交付。
4. 部署配置增加独立代码执行上限 `scripting`，分别控制沙箱与原生项目代码是否可请求授权，默认允许请求但不授予执行。显式 false 或畸形/未知版本输入拒绝；模型、项目、用户和 URL 不得放宽。既有配置保留打开模型能力。
5. `?scripts` 仅请求显示当前内容的授权流程。WebComponent 的显式允许绑定当前模型代际和脚本内容摘要；换模型、修改代码或撤销同意后失效。编辑器中明确保存/运行是对当前编辑内容的用户意图，但不得越过部署上限。
6. 原生项目代码在读取执行字节后计算完整 SHA-256，以项目 ID、模块路径及摘要绑定版本化同意记录。旧 v1 按项目 ID 的记录不被视为新授权。仅导入获准的相同字节；无字节的 URL 回退不能证明内容身份，拒绝执行。内置构建模块保持构建信任路径；原生代码仍具有页面权限，不能伪装成沙箱。
7. QuickJS 的取属性、调用、取结果/错误和桥接均处于有界 guest 操作内；嵌套调用不得延长外层 deadline。约束跨边界数据与资源，poison 后停用且禁止自动重试。宿主同步代码无法由 guest interrupt 强制抢占，需有界实现；Worker/异步 Tick 重构另议，不在本 ADR 中默认采用。
8. 独立渗透测试与复测是企业交付的额外证据。内部测试/扫描不冒充第三方报告，不自行批准真实设备或客户生产测试。

## Alternatives

仅扫生产 npm 依赖遗漏构建链；只读 lockfile 无法补全许可证正文；统一禁用 copyleft 不适用于本项目；把 URL/项目 ID 当永久同意无法绑定内容。立即迁到 Worker 会改变同步 SDK/Tick，未作为首选。

## Consequences

新增工具和门禁可能暴露既有发布阻断；没有修复/权利证据时必须真实报告失败。首次使用旧项目代码会重新提示；无字节 URL 回退需要提供自包含模块。公开页面内的授权仍不防御已经控制页面的主体。

## Compatibility and Migration

GLB/rv_extras、NodeId、项目文档 ID、脚本 SDK 与工业方向不变。新增部署字段只在已支持的配置版本生效。旧同意记录保留可识别性但拒绝授信，用户在明确新提示后创建 v2 记录；未授权代码不运行，模型仍可打开。供应链报告不写入项目状态，现有 CycloneDX 1.5 交付路径保留。

## Validation

策略正反例与真实扫描；许可表达式/过期例外/缺失和篡改证据；真实 QuickJS getter/序列化/桥接/poison；授权内容变化、加载竞争与撤销；原五项门禁、发布物摘要一致性及隔离生产旅程。真实平台、第三方报告、远程 required 配置分别留证。

## Rollback or Supersession

工具、VM 与同意迁移可分别回退；不能移除 required check 伪造通过。旧客户端会恢复旧授权语义，安全回滚需关闭相应代码入口或向前修复。记录原始报告，不把旧证据用于新制品。
