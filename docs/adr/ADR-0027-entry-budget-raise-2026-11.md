# ADR-0027：入口 chunk 体积预算提高到 3,600,000 字符

## Context

`tests/bundle-splitting.test.ts` 的 `ENTRY_BUDGET_BYTES` 约束每个访问者在首帧前下载的入口 chunk（`dist/assets/app-*.js`，按字符计）。[ADR-0001](ADR-0001-i18n-runtime.md) R1 规定该预算保持 3,520,000、不因 en-US 分包而放宽，T14 断言该值本身。

缺口整改第 4、5 步把新代码全部做成懒加载 chunk、英文文案移入延迟目录后，入口仍在增长：2026-11-03 `develop`（`51cf9b2`）实测入口 3,519,856 字符（gzip −9 为 1,066,118 字节），距预算仅 144 字符；入口与诊断运行时合计 3,543,339，距 EP-DIAG-001 的合计守卫 3,545,000 仅 1,661。

按 ADR-0001，zh-CN 是源目录与最终回退，必须整体留在入口（T12）。因此任何新增中文界面文案都会直接增加入口体积；在 144 字符余量下，下一项带界面文案的功能必然超限。测试历史（2026-08-23 条目）已记录：剩余可拆分的大模块（`ConnectPanel.tsx`、`layout-planner/index.ts`）是 T6 有意保留的非目标，其余是启动顺序或 i18n 决定，再降低入口需要产品决策而非配置调整。

用户在 2026-11-03 明确指示“入口体积预算先提高”（批准来源：用户当前明确指令）。

## Decision

1. `ENTRY_BUDGET_BYTES` 由 3,520,000 提高到 **3,600,000** 字符（相对实测 +80,144，约 +2.3%）。
2. 入口与诊断运行时的合计守卫改为相对预算表达：`ENTRY_BUDGET_BYTES + 25,000`（即 3,625,000），保持 EP-DIAG-001 当时 25,000 的余量关系，使两条守卫不会互相成为实际上限。诊断运行时自身 < 32,000 的上限不变。
3. 预算仍是棘轮：T14 改为固定新值 3,600,000。今后任何变动（提高或降低）都必须有新的已接受决定记录，并在测试的历史注释中写明实测值与归因。
4. 不改变的约束：zh-CN 整体在入口（T12）、启动 en-US namespace 在入口（T13）、非启动 en-US 在独立 chunk（T10/T11）、已拆分面板不得回到入口（T3/T4）、非目标保留（T6）。ADR-0001 R1 的“分包不得用来放宽预算”仍成立——本次提高是独立的用户决定，不是分包的回报。
5. 新功能仍按既有做法优先懒加载、英文进延迟目录；新增预算只用于无法移出入口的部分（主要是 zh-CN 文案与启动路径必需代码）。

## Alternatives

- **不提高，继续逐项挤出空间**：本轮第 4 步已为 ~13 KB 做过拆分与精简中文句子；剩余手段要么删减中文文案（损害 zh-CN 作为完整回退的契约），要么拆分 T6 保护的非目标面板（产品决定，且改动面大）。未采用。
- **把 zh-CN 也分包**：ADR-0001 R1 明确否决（chunk 取不到时界面只剩 key）。未采用。
- **按 gzip 计预算**：更接近传输成本，但改变测量口径会使历史记录不可比，且需要额外压缩步骤。本次不改口径。
- **更大的提高（如 3.8 M）**：余量过大会让“一个面板意外回到入口”（约 20–90 KB）不再触发 T5，失去棘轮的意义。未采用。

## Consequences

- 正面：后续数项带界面文案的功能可以在不触碰 zh-CN 契约的前提下合入；门禁继续拦截大块回退。
- 代价：入口上限增加约 80 KB 字符（按当前压缩比约 24 KB gzip），首屏下载与解析时间相应增加的上限；当前实际体积不变，增长发生在后续功能中。
- 长期约束：预算余量是共享资源，后续计划需在 Validation 中记录入口实测值；余量再次耗尽时，须先提出降低入口的产品方案或新的提高决定。
- 安全与兼容：无运行时行为、数据格式或协议变化。

## Compatibility and Migration

只改测试中的阈值与历史注释，不改变任何构建产物、GLB/`rv_extras`、项目文档、配置或插件接口。无需迁移。

## Validation

- `./scripts/verify.sh build` 后 `tests/bundle-splitting.test.ts` 全部通过：T5/T9 以新预算判定，T14 固定 3,600,000，诊断合计守卫以 `ENTRY_BUDGET_BYTES + 25,000` 判定，T3/T4/T6/T10–T13 不变。
- 测试历史注释记录 2026-11-03 实测（入口 3,519,856 / 诊断 23,483）与本 ADR。

## Rollback or Supersession

把 `ENTRY_BUDGET_BYTES` 与 T14 恢复为 3,520,000 即回退；前提是届时入口实测仍低于该值，否则回退需先完成相应的入口瘦身。未来调整须以新的 ADR 或 ADR 修订替代本决定。
