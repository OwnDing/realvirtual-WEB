# 浏览器、最低配置与内网信任验收

先查随版本交付的[支持矩阵](SUPPORT_MATRIX.zh-CN.md)。首批认证目标为 Windows 11 x64 Chrome/Edge；最低浏览器版本、CPU、内存、显卡数值须经实机留证后发布。旧“143 以上完整支持”由版本化矩阵替代。未验证不等于已知无法运行，API 检查通过不等于完整认证。

服务器与工作站 OS 分别验收。标准访问无需浏览器扩展、Java、ActiveX；Appliance 运行时、CONNECT 等工业网关和 XR 系统组件单列。标准 WEB 要求受信任 HTTPS 与 WebGL2；浏览器项目另需 OPFS；文件夹项目另需目录 API、权限与保存重开。浏览器项目/导入下载不是同步文件夹的等价替代。完整 Appliance 仍需 OPFS、服务健康、WSS；单文件演示按 L2-2 独立范围验收。

设置 → 诊断与支持提供环境检查；启动失败可访问部署基路径下 `compatibility/index.html`，Appliance 从 `/diagnostics/` 进入。点击开始才探测；OPFS 只写/读/删自有随机临时文件，目录权限按钮不写目录、不保留句柄。取消、超时、权限/配额、清理失败均可观察；迟到原生操作仍尝试清理。不要清空业务站点数据掩盖问题。L3-1 诊断导出保持被动采集。

报告显式下载，不上传、不连接工业服务，没有原始 UA、地址、目录名、资产、凭证、信号值或任意异常文本。请先查看后自行选择分享方式。

TLS 信任与离线许可证分别验收。优先企业 CA；internal CA 经 IT 批准的离线/GPO/MDM 流程分发根，以第二通道核对 SHA-256 指纹。见[安装手册](INSTALL.zh-CN.md)。不允许点击证书警告继续、关闭校验或忽略证书错误参数。核对 DNS、时间、SAN/主机名、链、到期、实际信任库和 WSS。浏览器只能报告安全上下文，不能读取证书链；localhost HTTP 不是生产 HTTPS 验收。续期保持 scheme/host/port，改变 origin 需显式迁移浏览器存储；iframe/XR 另验宿主权限策略。

最低配置记录 CPU/RAM/GPU/驱动/OS/浏览器/视口/画质/电源/虚拟机条件，附模型摘要、节点/三角形/材质/纹理/字节量和至少 30 次真实参考机性能基准。软件 GPU 仅为功能证据。WebGPU 是本产品实验性可选路径，核对实际后端与回退；XR 当前仅用经典 WebGL，按头显/固件/浏览器/运行时/VR或AR/输入方式验进入、交互、退出重进和释放。

交付前在受控环境验证最低/最高承诺浏览器、真实 Chrome/Edge、目录保存关闭重新授权重开及拒绝、浏览器项目备份恢复、真实 HTTPS/WSS 与证书负例。缺少实机或证据保持未验证，工程测试不会自动提升认证等级。
